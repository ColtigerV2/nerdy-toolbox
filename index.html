About this project

Built to learn by building.

Nerdy Toolbox is a small static web project. It is intentionally simple, easy to host on GitHub Pages and useful as a playground for HTML, CSS and JavaScript.

Future versions can add more calculators, workshop helpers, FPV tools, small productivity widgets or anything else that feels useful and fun.
