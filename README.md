# ColtigerV2 Toolbox

Eine kleine Sammlung persönlicher Web-Tools und Scripts von **ColtigerV2**.

## Schnellzugriff

| Tool | Beschreibung | App-Link |
| --- | --- | --- |
| Schmelzepumpen-Rechner | Berechnung von Pumpenwerten und Geschwindigkeit auf Basis von Stärke, Geschwindigkeit und Pumpendrehzahlen. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/melt-pump-calculator/) |
| Rollenwechsel-Rechner | Berechnet den nächsten Rollenwechsel aus bekanntem Wechselzeitpunkt, Rollenlänge und Geschwindigkeit. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/roll-change-calculator/) |
| Umstelllisten-Assistent | Vergleicht alte und neue Auftragswerte und erzeugt eine Umstellliste, inklusive OCR-Unterstützung. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/changeover-assistant/) |
| Geschwindigkeitsrechner | Berechnet die neue Geschwindigkeit bei gleicher Pumpe anhand von Stärke 1, Geschwindigkeit 1 und Stärke 2. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/speed-calculator/) |
| Stempelzeiten | Lokaler Arbeitszeit-Tracker mit CSV-Export und JSON-Backup. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/time-tracker/) |
| Rollenberechnung | Berechnet Rollendurchmesser, Rollenlänge und Rollengewicht. | [Öffnen](https://ColtigerV2.github.io/toolbox/scripts/roll-calculator/) |

## Code-Pfade

```text
scripts/melt-pump-calculator/
scripts/roll-change-calculator/
scripts/changeover-assistant/
scripts/speed-calculator/
scripts/time-tracker/
scripts/roll-calculator/
```

## Hinweis

Die Tools sind einfache HTML/CSS/JavaScript-Web-Apps. Einige Apps speichern Daten nur lokal im Browser des jeweiligen Geräts. Diese privaten Daten werden nicht in GitHub gespeichert.
